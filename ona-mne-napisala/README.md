# Она мне написала?!

Аниме-новелла в формате переписки для Яндекс Игр. Вся игра — один файл `index.html` (HTML5 + CSS3 + чистый JavaScript, без сервера и внешних зависимостей).

## Что внутри

- 5 сюжетных глав, 103 сюжетных узла, около 240 уникальных реплик, 80 выборов.
- 4 концовки: «Дверь», «Свет», «Тишина» и секретная «Петля» (нужны все 5 улик + секретный ответ в главе 5).
- Доверие (ключ) и дружба (сердце), 8 эмоций Акиры, реакции на сообщения, фото-«полароиды» с кликабельными уликами.
- 25 достижений, ежедневная награда (7-дневный цикл), 3 экстра-главы за звёзды, три темы чата.
- Только добровольная реклама: удвоить награду, подсказка, звёзды в магазине. Межстраничная реклама выключена.
- Сохранение в localStorage (и в облако Яндекса, если SDK доступен), «Продолжить», переигровка глав, полный сброс.
- Адаптация под телефоны (портрет/альбом) и ПК, сенсорное управление.

## Оформление «Натрий»

Ночь за окном, жёлтый свет фонарей, бумага и чернила. Засечный курсив для заголовков, моноширинный шрифт для служебных подписей, зерно плёнки поверх всего. Эмодзи в игре нет: иконки нарисованы вручную (`glyph.js`), реакции Акиры — каомодзи, а в репликах вместо смайликов — русские скобочки, как в настоящей переписке.

Мелочи, которые стоит поискать:

- **Мочи и лазерная указка.** На подоконнике сидит кошка. Красная точка следует за курсором (на телефоне — за пальцем): Мочи крадётся, виляет задом и прыгает. Если не трогать мышь, точку начинает водить кто-то за кадром. Без точки Мочи засыпает. Клик по ней — мурчание. Семь поимок — достижение «Красная точка».
- Луна меняет фазу по клику; птица на проводах переминается и иногда улетает; по горизонту проходит поезд; по комнате скользят фары машины; у фонаря кружат мотыльки, а сам фонарь иногда моргает.
- Одно из окон дома напротив — 48-е — подрагивает. Часы на обложке показывают настоящее время; ровно в 23:47 окно загорается красным.
- В чате: галочка превращается в двойную, когда Акира начинает печатать; при наведении на вариант ответа он «набирается» в поле ввода; на ПК есть статус-бар телефона с часами переписки и батарейкой, которая садится по ходу разговора.
- Фото приходят как полароиды и «проявляются», уведомления похожи на оторванные чеки, достижения — латунные значки, заставка главы — отсчёт киноплёнки.

## Запуск локально

Просто откройте `index.html` в браузере. Без SDK реклама работает как заглушка (3 секунды → награда).
Режим отладки: `index.html?debug=1` (объект `window.__GAME` в консоли).

## Загрузка в Яндекс Игры

1. Возьмите архив `ona-mne-napisala-yandex.zip` из корня репозитория (в корне архива лежит `index.html`).
2. Консоль разработчика Яндекс Игр → «Добавить приложение» → загрузите архив в черновик.
3. Заполните карточку: название, описание, иконку и обложку.

## SDK Яндекс Игр

Настройки — в блоке `window.CONFIG` в начале скрипта внутри `index.html`:

```js
yandex: { sdkUrl: '/sdk.js', cloudSave: true, timeoutMs: 3500 },
ads: { interstitialBetweenChapters: false, interstitialCooldownSec: 180, stubDurationSec: 3 },
```

Используется `LoadingAPI.ready()`, `GameplayAPI.start()/stop()`, `adv.showRewardedVideo` (только по нажатию игрока) и `player.getData/setData` для облачного сохранения. Если SDK не ответил за `timeoutMs`, игра продолжает работать с localStorage.

## Свои арты вместо заглушек

Акира нарисована встроенной векторной заглушкой (SVG). Чтобы поставить свои изображения, положите файлы рядом с `index.html` и укажите пути в `CONFIG.images` (PNG/WebP с прозрачным фоном, портрет 3:4). Пустые эмоции остаются векторными.

## Где что править

Скрипт внутри `index.html` разбит на блоки: `config.js` (настройки, награды, цены), `art.js` (графика), `story.js` (главы, реплики, выборы, концовки, достижения), `glyph.js` (иконки), `engine.js` (движок), `ambient.js` (живые детали обложки и чата). В текстах интерфейса иконки задаются токенами вида `:moon:`.

Сохранения прошлой версии совместимы: ключ сохранения и id тем не менялись, эмодзи из старых логов переписки при показе превращаются в иконки или убираются.
